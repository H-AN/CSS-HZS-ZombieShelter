# CSS-HZS-ZombieShelter

CS:S 大灾变的独立昼夜求生插件，当前版本 **0.1.0 / 设计1.7**。与 HZS 2.3.2 的既有 API 接入；**没有修改 HZS 主体源码，也没有新增丧尸生成 API**。

本版使用主体原生生成/补怪：本图开局60只普通怪构成常驻池，白天传到地图活动区域外并隐藏、冻结；晚上按当天数量分批随机回到合法 T 点。普通怪真实死亡后，主体照常补怪，新实体进入同一池。Boss 通过主体已支持的 Stage `customzombies` 开局创建一次，再由外部插件在初始化完成后0.1秒传到唯一 Boss target。

**索敌完全沿用主体**：外部读取 `CHostage.m_leader` 获取主体当前目标，没有重新寻找最近玩家或循环锁定玩家。近墙时调用已有 `Han_SetCustomAnimationEx`，主体在自定义动画期间暂停普通攻击；外部按间隔减少建筑耐久，解除接触后交还主体。目标锁定 API 只用于白天停放和未唤醒 Boss 的自锁休眠。

当前已经实现日夜计时、三基地和室内保护、屋外扣血、五类材料采集与渐显恢复、团队材料、刀修/材料升级、机枪塔/火焰塔/围栏/地雷、建筑攻击、Boss休眠与唤醒、胜利换图、失败退天和存活设施重建。**按每天的模板概率主动生成不同怪物暂缓**；本版天数改变启用数量和血量，原生怪物种类取决于主体 Stage 的普通池。

## 安装

1. 已有能正常运行的 HZS 主体、SourceMod1.12、Metamod，以及主体配置引用的 NPC 模型/声音。这里不包含主体 SMX，也不覆盖主体的全局模板文件。
2. 使用2026-10-14制作的 `zsh_desertplant_cso_v1_d.bsp`。地图纹理、基地/材料/防御模型及 NAV 已内嵌；无需再次散装部署这些地图模型。
3. 将本仓库 `addons` 合并到服务器 `cstrike/addons`。主插件是 `plugins/HanZombieShelter.smx`；13份外部配置位于 `configs/HanZombieShelter`。
4. 一并安装提供的**本图** `configs/HanZombieScenario/zsh_desertplant_cso_v1_d/HanZombieScenarioStage.cfg`。若服务器原来已有同名覆盖文件，先保留备份。这只调整本图关卡配置，不改核心代码/其他地图配置。
5. 重新加载地图开始。中途加载插件或修改模型/坐标后，请重新加载地图；战役中不热换一半配置。

默认普通模板 key 为 `putong_stage1`；固定 Boss key 为 `boss_pangzi`，API 公共名字为“巨型狂暴形态僵尸”，来自主体仓库的示例模板。实际服务器模板不同，应一起对齐本图 Stage 和 `bosses.cfg`；**配置 key 与 API 公共名字是两个字段**。

核心已有的复活和全灭判负继续使用。此插件没有第二套复活 timer，不通过伪造 Han 胜负 forward 判定结果。Boss 通关直接显示 HUD 后按服务器地图循环换图；所有基地摧毁时由外部提交失败并结束真实回合。

本插件自带受控的自动防御模块，不需要再加载旧 HZSTurret/FlameGuns 来生成同一批设施；避免并行重复创建/重复扣材料。

## 玩家操作

- 刀击材料：成功采集一次，次数耗尽后逐渐恢复；生长中不能采集、不会阻挡。
- 枪击基地/设施：不扣耐久。刀击受损建筑：修复耐久，上限为本等级最大值。
- 瞄准基地/设施按 **E**：材料足够时升级这一座；持续按住不会连续收费。
- 聊天输入 **!build** 或控制台 `sm_build`：选择配方，在瞄准的平坦地面建造。
- **!materials / sm_materials**：查看全队木、铁、铜、银、金库存。
- 黑夜进入任一存活基地：只免屋外环境伤害，仍会受到合法 NPC 攻击；屋顶和基地外围不算室内。
- 休眠 Boss 不会主动追人，机枪/火焰塔不会自动打它。有效伤害使它苏醒；玩家地雷可唤醒。日夜切换不清除 Boss，也不让其自动回家。

## 配置文件

| 文件 | 功能 |
| --- | --- |
| mode.cfg | 日夜时长、环境扣血、交互距离、T玩家出生策略、设施上限、只在本模式应用的服务器ConVar |
| lifecycle.cfg | 退天/直接失败换图、召唤物保留开关、升级基地恢复比例、结果文字和展示时间 |
| resources.cfg | 五材料模型/颜色、采集次数/产量、相对权重、恢复时间、材料容量 |
| zombies.cfg | 原生池数量、活动怪上限、隐藏停放点、近墙攻击距离/伤害/间隔 |
| days.cfg | 天数区间、每夜启用数、补入速度、血量成长和上限、掉落倍率 |
| bosses.cfg | 公共名字、模板key、固定Boss最大HP与建筑攻击参数 |
| bases.cfg | 基地模型、各级耐久、刀修量、材料升级配方 |
| turrets.cfg | 两种机枪塔、等级伤害/射程/间隔、建造与升级材料 |
| flame_turrets.cfg | 自动扇形火焰、多目标、后续燃烧、等级与配方 |
| fences.cfg | 可被丧尸攻击的围栏模型、耐久和配方 |
| mines.cfg | 接近触发、爆炸伤害/范围、耐久和配方 |
| drops.cfg | 真正战斗击杀的材料概率/数量/权重 |
| maps/zsh_desertplant_cso_v1_d.cfg | 三基地位置与OBB、CT安全点、32个材料节点、Boss target、场景路障与出生禁建柱 |

只有存在地图配置的地图才启用，其他PVE/ZE地图继续由原主体运行。默认180秒白天/180秒黑夜、屋外每秒10HP。数值为可调整的首版配置，尚未经过多人长期平衡测试。

`destroy_summons_on_failure=0` 保留存活的塔、火焰塔、围栏和未爆地雷，下一真实回合免费重建；`1` 清空。已经炸掉的雷/战斗摧毁的设施不会复活，也不会返还建造材料。三基地全部毁才失败，单座毁可转移。升级基地保留等级和最大HP，恢复到不满血；未升级基地恢复基础状态。材料与采集成长进度在同地图战役内保留，换图/服务器重启开始新战役。

## 管理员与构建

`sm_zsh_status` 查看状态。ROOT管理员可用 `sm_zsh_phase day|night`、`sm_zsh_day <天数>`、`sm_zsh_grant <wood|iron|copper|silver|gold> <数量>`、`sm_zsh_fail`。`sm_zsh_reload` 只允许还没建立战役时重试加载；战役中修改配置需要重新载入地图。

PowerShell运行 [build.ps1](build.ps1)，可以通过参数指定 `spcomp64.exe` 和SourceMod include目录。源码入口是 [HanZombieShelter.sp](addons/sourcemod/scripting/HanZombieShelter.sp)，按 Config / Geometry / World / NPC / Combat / Lifecycle / Commands 分模块。

测试入口 [ShelterIntegrationProbe.sp](tests/ShelterIntegrationProbe.sp) 会包含真正的生产源码并添加隔离断言，联合未改动的 HZS 主体测试。**测试SMX不安装到生产目录**。当前测试范围与结果见 [开发与验收记录](docs/开发与验收记录.md)。

本机 Dedicated Server 的备份、测试启动与恢复方法见 [本地服务器说明](docs/本地服务器测试与恢复.md)。`server-support` 是从主体源码包搭建空服务器时缺失文件的补充，已有完整主体安装请保留自己的翻译与NPC资源。

## 接入边界

停放怪仍登记在主体中，因此主体自己的“活怪总数”可能包含隐藏池；本插件 HUD 显示实际启用夜袭数。死亡通知、奖励和补怪仍走主体，白天停放不调用杀死/删除 API。

主体伤害入口当前要求有效玩家归因。自动设施使用在场存活合作玩家作为伤害代理，材料发到团队仓库；不依赖最初建造者仍活着或在线。Boss HP与激活状态持续保留影子数据，避免主体先清怪再通知失败时丢档。

采用 EntRef、ClientSerial、回合epoch、建筑稳定id和实例generation。异步传送和菜单检查身份，建造检查完整模型范围/出生保护柱，正在攻击建筑的NPC会停止追人并暂停其对玩家的穿墙近战。火焰只使用一次直接伤害与共享燃烧调度，不叠加env_fire的伤害。

未来如果要每一天按概率主动创建特定模板，再添加/接入通用生成API；这不是本版运行的前提。99999关卡阈值仍是有限值，不宣称数学上的无限；Boss通关是外部条件。
