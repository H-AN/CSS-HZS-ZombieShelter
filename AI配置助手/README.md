# 昼夜求生 v0.8.2：配置百科与 AI 修改助手

本目录帮助AI理解插件各模块，将服主的自然语言要求转换成准确的配置修改。可以随时查询、改数值、改配方、修复坏配置、添加现有机制支持的类型，或采用轻度／重度起点，无需每次重新完成整套问卷。

修订：2026-10-27／百科与工作副本版。

## 直接开始

将本目录交给AI，例如：

> 请读 README.md 和 01_AI工作流程.md，按需查阅配置百科。仓库示例只作来源与修复参考，保留我已经改过的数据。配置位置是〈真实服务端位置或工作目录〉，请帮我把〈对象和要求〉改好。必要信息不足时每轮最多问五项。

没有位置也可以直接问：

> 昼夜都改成100秒，应该改哪个cfg、哪个字段？

## 三种位置情况

| 用户提供的信息 | AI的处理 |
| --- | --- |
| 真实服务端或其配置位置 | 读现有配置，备份后在目标最小修改，保留其他用户数据；写盘与运行生效分开说明 |
| 指定工作目录或已有副本 | 在指定目录修改；已有配置就沿用，首次空目录才复制匹配版本的完整示例后调整 |
| 没有任何位置 | 说明相对cfg、完整字段、建议值与关联，推荐给工作目录或真实位置让AI代改；不猜路径、不创建输出、不声称已改 |

已提供的有效位置继续沿用。路径不可读写时说明限制，先按第三种模式回答。无需提供服务器密码或远程账号。

## 仓库只读，当前用户数据优先

仓库 addons/sourcemod/configs 是只读来源，用于查结构、溯源和修复对照。不能修改仓库示例，也不把用户合法自定义当作错误还原默认。

首次空目录复制完整示例后，后续一直修改当前副本。用户改过的数值、ID、配方和其他内容优先保留。改坏时先保存坏文件，比较最近正确副本／用户备份／仓库参考，只修确认的范围。无法恢复的用户值要询问，不能整套重新复制抹掉数据。

用户工作目录维护完整配置树。只改六个文件时，其他文件仍是最终结果的一部分；交付完整结果时不能让用户从变化文件和备份手工拼装。增量导出可另附并说明依赖。

## 前置与能力

首次整体开服需确认HZS主体/API、Metamod、SourceMod 1.12、资源和翻译、已适配地图、本图指定Boss五槽及匹配定义／Stage。缺项不能称为可运行；独立解释、离线改值和局部修复可以继续，同时保留部署待办。

这里只配置已有机制，不制作地图、不采点找坐标、不制作模型或开发引擎功能。用户准备好资源后，可配置已有建筑机制支持的新类型。

有指定位置时按[配置会话模板](模板/配置会话.json)记录来源和修改；无位置只在对话记录，不擅自落盘。编辑cfg不自动执行重载、切图或启停游戏。
