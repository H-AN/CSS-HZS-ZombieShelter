# 首版实现与验收

2026-10-14，版本0.1.0，设计修订1.7。实现位于本仓库；HZS 2.3.2主体及旧炮塔、旧火焰脚本保持原样。本版按照“暂不补生成API”的决定运行。

## 主体与外部的分工

| 主体已有能力 | 外部接入 |
| --- | --- |
| 普通怪生成、死亡、原生Reborn | 创建forward完成后登记EntRef，白天停放、黑夜随机合法T点启用 |
| 最近玩家索敌与行走 | 读取原生CHostage的m_leader，完全复用当前目标 |
| 自定义动画API | 靠墙播放模板attack_anim，按独立耐久模拟一次建筑攻击 |
| 玩家复活、全灭检查 | 不再建复活timer；接Han_OnZombieWin执行统一失败策略 |
| Han_SafeDamageZombie | 防御设施通过存活合作玩家归因，使用实际死亡forward |
| Stage的customzombies | 开局一次固定Boss，通过公共名字识别，初始化后0.1秒定位 |

主体`ZombieThink`先检查`IsCustomAnim/CustomAnimEndTime`，有效期间提前返回，因此攻击动画与普通攻击互斥。外部只在墙接触过渡及建筑攻击期间阻止该NPC对玩家造成伤害，没有另写追人AI。离开接触或建筑摧毁时释放短动画、恢复移动，主体重新接管。技能扩展也可继续使用主体的动画接口。

固定Boss不依赖距离感知开关：休眠时自锁目标且冻结，真实HP下降后唤醒并释放给主体追人。Boss不会因天亮被停放；自动机枪/火焰塔跳过未唤醒Boss，玩家攻击和玩家地雷仍可主动唤醒。

## 世界与资产

默认白天/黑夜各180秒，只用文字倒计时。夜间脚下位置不在任一存活基地的室内OBB并集，就每秒扣10点真实HP。屋顶、地下、基地周围不算安全；保护只针对环境伤害。

三基地由外部创建可控实体，枪击不扣耐久，刀击修复，瞄准按E消耗配方升级。单座损毁可转移，全部损毁触发失败。升级保留缺失HP差额，防止E升级顺带免费补满血。

材料节点是支持原生EnableCollision/DisableCollision的`prop_dynamic_override`，成熟时可刀采，次数耗尽后停用碰撞和交互，按配置恢复透明度，完全成熟才恢复次数。只改固体标志会留下旧引擎碰撞，已经改用原生输入。参考[Valve Source SDK 的动态实体碰撞输入实现](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/props.cpp)。

建造首先检查完整模型范围、地面、玩家距离和出生禁建柱，之后原子扣材料，创建失败则退款。测量用的临时模型先关闭碰撞，避免同一帧重复建造被尚未清理的临时模型拦住。

防御组包括两类机枪塔、扇形多目标火焰塔、围栏和一次性地雷，均独立配方/等级文件。火焰持续伤害用统一调度，连续命中延长燃烧，避免每次射击重置伤害计时而永远不触发后续伤害。地雷先提交消耗，再调用伤害入口，防止死亡forward重入重复引爆。

同地图失败的保存对象是数据：材料、基地等级/耐久、存活设施类型/位置/角度/等级、采集成长进度、Boss HP与唤醒状态。真实回合开始重建实体，不保存旧实体编号。`destroy_summons_on_failure=0`免费恢复存活设施，`1`清空；已爆地雷和战斗摧毁的设施不复活。升级基地恢复不满血，基础基地重新建立。内存保存不跨换图/服务器重启。

所有必杀Boss死亡后显示肃清HUD，再使用服务器地图循环换图。没有假造Han胜利通知，也没有添加回合胜负native。同帧出现基地全毁和确认Boss死亡时，确认胜利优先。99999是沿用原生Stage的有限桥接阈值，尚未到阈值前由Boss决定胜利。

## 引用与初始化

核心CreateZombie中的创建forward发生在初始化中间，所以这里只登记、隐藏，下一帧再操作移动/碰撞，Boss再延迟0.1秒定位。保留主体m_iName中的装饰实体引用，不擅自改名。实体用EntRef、玩家用ClientSerial，延迟回调和建造菜单检查回合epoch；注销绑定由稳定引用核对。装饰清理只在身体销毁后检查失去父实体的装饰，不删除其他模块仍采用的模型。

当前注册容量128，普通池上限60，给死亡身体、替代怪和Boss留出重叠预算。T回场检查真实NPC体积和向下34单位的落点路径，跳过被其他活动NPC占用的位置。出生仍为地图地面上36单位；不会把怪直接贴在地面或建筑内。

`m_vecMins/m_vecMaxs`已经是当前碰撞范围，不能再乘一次模型scale。实测普通怪±13、高72，Boss±26、高144，唯一Boss target能容纳。参考[Valve碰撞范围缩放实现](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/shared/collisionproperty.cpp)。

## 已知范围

- 当前每天改变活动数量和HP，不按每日模板概率主动生成；将来需要通用生成API时再接入。
- 视觉日夜仍使用文字，没有动态灯光/天空切换。
- 主体HUD可能显示隐藏池总量；外部HUD显示实际夜袭数。
- 多人长时间压力、经济平衡及完整实战手感尚需试玩；自动断言通过不能代替多人实战。
- 当前只实测本图和本地HZS2.3.2。服务器模板key/公共名字变动必须对齐Stage和bosses.cfg；没有地图配置的地图不启用外部模式。
- 旧源码中关服时仍存在GameRules销毁后结束回合的路径；本次测试结束后，先用SourceMod卸载主体，使其清理逻辑在GameRules有效时执行，再关闭引擎，未为此改主体。
