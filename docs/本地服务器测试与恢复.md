## 启动与连接

日常使用只加载 `UnmodifiedHZS.smx` 与正式 `HanZombieShelter.smx`，并安装 `addons/sourcemod/translations/HanZombieShelter.phrases.txt`。测试探针只用于自动回归，结束后恢复正式二进制。

本机此前出现“127.0.0.1 的 TCP RCON可达、游戏UDP无法连接”的情况。真实客户端测试绑定当前局域网地址 **192.168.0.102**，不要用RCON连接成功推断游戏连接也成功。在仓库执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Start-LocalShelter.ps1 -ListenAddress 192.168.0.102
```

脚本默认隐藏启动。客户端控制台连接同一个监听地址和端口：

```text
connect 192.168.0.102:27129
```

若机器IP变化，先查询本机地址，再调整 `-ListenAddress` 与客户端 `connect`。仅运行服务端RCON自动检查时可以使用127.0.0.1；实际客户端可达性必须单独确认。启动脚本也可复制为服务器根目录的 `启动昼夜求生测试.ps1`。

脚本生成本机RCON密码并保存在服务器根目录 `.zsh-local-rcon.txt`，也可用 `-RconPassword` 指定。密码不进入仓库、安装包或测试报告。客户端设置自己的 `rcon_password` 后，可执行 `rcon sm_zsh_status`、`rcon sm_zsh_phase night` 等命令。

关服前用RCON执行 `sm_zsh_fail`，等真实回合结束，再执行 `sm plugins unload UnmodifiedHZS` 和 `quit`。先卸载主体让清理在GameRules仍有效时运行，可避免旧主体关服顺序异常。
