# 配置说明

主配置目录为 [`plugin/addons/sourcemod/configs/HanZombieShelter/`](../plugin/addons/sourcemod/configs/HanZombieShelter/)，安装后位于 `cstrike/addons/sourcemod/configs/HanZombieShelter/`。服主可直接在默认配置基础上调整玩法。

配置使用 KeyValues 格式。修改时保留根名、层级、引号、材料 ID 和被引用的类型名，先保存工作副本再测试。

## 当前默认数值

| 项目 | 默认值 | 位置 |
| --- | --- | --- |
| 白天／夜晚时长 | 180／180 秒，入夜预警 30 秒 | `mode.cfg` → `Rules` |
| 夜间暴露 | 开启，每 1 秒 1 点伤害 | `mode.cfg` → `Rules` |
| 真实施工 | 开启，建筑放置后需要工具命中施工 | `mode.cfg` → `Rules/real_construction` |
| 五种基础资源收益 | 每次有效命中基础 10，另受工具和技能倍率影响 | `resources.cfg` → `Gatherables` |
| 资源再生时间 | 木45、铁60、铜90、银120、金180秒 | `resources.cfg` → `grow_seconds` |
| 个人／基地仓库容量 | 配置为0，表示不设置常规容量限制 | `resources.cfg` → `Inventory`、`BaseStorage` |
| 普通刀工效 | 施工10、维修10、采集倍率1.0 | `weapons.cfg` |
| 斧头工效 | 施工200、维修150、采集倍率2.0 | `weapons.cfg` |
| 技能 | 每天2点，多数20级，每级1点；重力最多9级 | `skills.cfg` |
| 合成台 | 最多10级，每基地1台；耗电50＋每级30 | `workbenches.cfg` |
| 完工建筑拆除 | 返还实际投入的50%；未完工取消按实际投入全额返还 | `management.cfg` |
| 生存救援目标 | 30天 | `lifecycle.cfg` → `Campaign/survival_day_limit` |

费用和倍率是当前默认玩法，不是固定规则。例如提高采集收益通常也应同时审阅建造、升级、材料合成费用与背包容量。

## HZS、环境与武器配置

| 目录 | 负责什么 |
| --- | --- |
| `configs/HanZombieScenario/` | 原生 NPC 模型、基础属性、音效、普通列表和各地图 Stage |
| `configs/HanZombieShelterEnvironment/` | 昼夜天空和地图环境 |
| server-compat 中的 `configs/HanWeaponSystem/` | HWS 武器、命令、动作和购买配置 |
| server-compat 中的 `configs/DeltaForceKnife.cfg` | 对应十刀插件设置 |

`HanZombieShelter/skills.cfg` 只控制玩家技能。外部丧尸技能由其插件决定；不能在这个文件中配置丧尸的迷雾、自爆、治疗等技能，也不能假定所有外部技能都提供独立 cfg。

## 修改例子

### 调整昼夜

要把白天延长到240秒、夜晚设为120秒，只修改 `mode.cfg` 中已有叶值：

```text
"Rules"
{
    "day_seconds" "240"
    "night_seconds" "120"
}
```

这只是局部示例，其他原字段继续保留，不能拿片段覆盖整份文件。

### 调整采集收益

在 `resources.cfg` 的目标 `Gatherables` 项中修改 `yield_per_successful_hit`。例如木材由10改为5，只改木材这一项；`weapons.cfg` 中斧头的2倍和玩家采集技能仍会影响最终收益。

要增加稀有材料出现概率，修改资源池的 `Weights`。权重按相对比例抽取，不要求总和100；不能把整个池全部设为0。

### 调整炮塔与设施

对应配置中通常由 `Types` 定义模型、功能和等级，`BuildRecipes` 定义建造入口及费用，`Levels`／`Growth` 定义升级属性与费用。改类型标识后，应同步所有 `output_type` 等引用。

改模型时，同时检查尺寸、放置偏移、动画、模型侧件、材质以及 Downloads。不要只更改模型路径而遗漏客户端资源。

电网默认在缺电时按优先级分配。`power.cfg` 的 `overload_penalty` 可调整为整座基地正耗电设备一起停用的模式；运行时 `sm_zsh_power_overload` 的 `-1` 使用配置，`0` 为优先级分配，`1` 为过载停用模式。

## 合成台与配方

| 字段 | 含义 |
| --- | --- |
| `workbenches.cfg/Types` 的组名 | 台型的精确标识 |
| `required_station_type` | 武器配方需要的台型；省略时绑定第一个可用台型 |
| `required_level` | 所需台等级，省略为1 |
| `cost` | 消耗的个人材料，键必须是已注册材料 ID |
| `command` | 已注册的单个无参数外部武器命令；不能写参数或命令链 |
| 材料配方 `output/material`、`output/amount` | 产出的材料和数量 |

默认11条武器配方包括斧头和十刀；`apexshuangren` 使用的命令是 `sm_shuangren`。台升级费与制作武器费分别支付。没有外部武器插件时应关闭或替换对应配方，不要保留无效命令。

材料配方默认包含四条100换1的逐级材料转换，以及金10＋银20＋生存币5合成瘟疫核心1。材料合成对所有可用台型和等级开放，但仍需供电、足够输入以及完整容纳产出。

## 修改何时生效

普通配置在正常地图／战役加载时读取，技能需要新地图会话。`sm_zsh_reload` 仅用于尚未建立战役时重试；不要靠清库存、重放回合或强制重生来让设置生效。

修改前保存旧文件，先检查菜单和日志，再安排真人检查。不同人数与地图可使用不同数值，不需要修改插件源码。
