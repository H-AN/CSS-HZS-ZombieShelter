# 修改检查、完整工作副本与交付

适用v0.8.2。规则见[01](01_AI工作流程.md)，字段见[04](04_配置目录与字段速查.md)，操作见[07](07_自然语言修改与新增炮塔.md)。按本次需求检查，小修改不要求全配置问卷。

## 三种成果

| 模式 | 成果 |
| --- | --- |
| 真实位置 | 目标文件最小修改并读回，其他用户数据保持；未自动加载 |
| 工作目录 | 完整副本持续更新，空目标首次复制有记录，后续沿用当前数据 |
| 无位置 | 对话说明cfg／字段／值并推荐目录，不落盘、不创建输出 |

仓库原件只读。坏配置先备份局部修，合法自定义优先。

## 相关检查

| 改动 | 检查重点 |
| --- | --- |
| 通用 | KV根/schema、唯一键、类型、有限数和精确差异，未涉及用户数据保持 |
| 昼夜 | 分别改两个持续时间，提示提前量合理，只改一项时另一项保持 |
| 炮塔 | 类型／等级明确，damage与fire_interval真实支持，0.2秒是每秒5次，方向矛盾先问 |
| 造价 | 选定BuildRecipes的cost；只木1铁1须只剩两叶，其他配方和材料注册保持 |
| 血量／等级 | 最大HP与初始HP相容，目标等级范围、Growth及显式等级优先规则准确 |
| 资源 | 权重与独立RegrowWeights、等待／生长、次数／产量／倍率、每种材料容量分别核对 |
| 怪物 | 阶段连续、目标不超原池和活动上限、共同预算合法，不自动改Stage |
| 电网／合成 | 供需、台型、等级、材料、外部命令引用；未知注册状态标待测 |
| 技能／篝火 | 点数、效果上限、燃料／耐久分别检查，不补发旧天数点数 |
| 新增类型 | 唯一ID、必要块、等级／Growth、配方引用、资源及炮口放置资料，见07 |
| 修复 | 损坏原件保留，修复有依据，无关自定义保持，未知原值已说明 |

共同NPC约束含2×initial_ordinary_count＋Stage全部customzombies数量≤512，硬边界不代表推荐负载。显式RegrowWeights完整替代再生表，漏项为零。离线检查不代表碰撞、路径、武器交付或平衡通过。

## 写入与保留

1. 检查实际源／目标，不经别名写回仓库示例。
2. 在用户允许范围备份本次目标原始字节，分别记仓库参考与用户当前哈希。
3. 从用户当前文件制作最小差异，新增／删成本叶也限请求范围。
4. 提交前再核对目标哈希；有后续变化先合并最新内容。
5. 写回读回解析，核对新值及保留项；回滚整文件也要目标匹配本次写后哈希，否则停止自动恢复。
6. 简短告诉用户路径、改变和生效条件，不要求新手读大批报告。

示例不可用时请求匹配参考，不能先改源再复制，也不能用默认重铺解决已有用户数据。

## 完整工作树与导出

工作目录维护：

~~~
<用户工作目录>/
  addons/sourcemod/configs/
    HanZombieShelter/<当前完整配置及子目录>
    <已有来源且本任务需要的其他配置>
  配置记录/<来源、摘要、备份>
~~~

目标已是配置目录时保留原层级；真实服就地保留完整树。

用户要整套导出时，从当前用户树制作：

~~~
<用户指定交付目录>/
  完整最终配置/addons/sourcemod/configs/...
  增量覆盖/addons/sourcemod/configs/...   # 可选，只含变化文件
  配置说明.md
  文件清单.json
  原始备份/                            # 与结果分开，不用于手工拼装
~~~

完整结果包含范围内未变文件的原字节；增量省略未变文件。六份变化不等于完整树只剩六份。实际地图／原生资料没有取得时列缺项，不拿占位或别图补齐；完整配置不等于完整安装包。

无位置不创建目录或ZIP，只说明字段并推荐目录。已有自定义未取得时不能用仓库默认生成覆盖它的包。

覆盖测试应先备份、核对导出后有无新变动，再将结果内addons合并到实际cstrike，只替换清单同名文件、保留其他内容，不递归删除目录。用户后续改动先重合并；附加增量依赖同一完整基线。

## 完成状态与生效

单项只记录相关文件和未涉及范围；整套配置逐文件登记用户自定／预设／保留／未启用／缺项、来源与最终哈希、是否进入完整／增量。

分别报告请求已处理、文件已检查／写回、工作树范围完整、部署条件就绪、实际已加载／实测，不能互相代替。模拟可完成副本，但安装或地图缺项不能称真实服即用。

主sm_zsh_reload在已有快照或回合准备后可能拒绝；技能变化需新地图会话。sm_zsh_reload_weapons只读刀具工作规则，部分运行Cvar可覆盖。编辑文件不自动执行命令或结束当前局。

## 反馈继续改当前副本

先确认是否已加载新值，读最新用户文件与历史。资源少区分概率、再生、产量；炮塔弱区分伤害、间隔、成长、门禁与供电。只改接受的相关项，不重套全预设、不删除后来新增条目。

整体初配可检查加载、采集建设、电网配方、昼夜与Boss；单项无需重做全套。这里不提供地图采点或开发夹具。
