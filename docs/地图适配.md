# 地图适配

当前默认地图为沙漠 DN 和死城 DN。地图文件、Shelter 配置、HZS Stage、基地／Boss类型、环境与灯光校验需要配套使用。

## 已提供的默认地图

| 地图 | 基地 | Boss | 配置 |
| --- | ---: | --- | --- |
| `zsh_desert_han_dn` | 2 | 胖子、安哥拉、异形斗兽各1 | [Shelter地图](../plugin/addons/sourcemod/configs/HanZombieShelter/maps/zsh_desert_han_dn.cfg) · [HZS Stage](../plugin/addons/sourcemod/configs/HanZombieScenario/zsh_desert_han_dn/HanZombieScenarioStage.cfg) |
| `zsh_deadcity_han_dn` | 6 | 胖子1 | [Shelter地图](../plugin/addons/sourcemod/configs/HanZombieShelter/maps/zsh_deadcity_han_dn.cfg) · [HZS Stage](../plugin/addons/sourcemod/configs/HanZombieScenario/zsh_deadcity_han_dn/HanZombieScenarioStage.cfg) |

BSP／NAV 位于[资源分卷包](../resources/README.md)解压后的 `maps/`；两图的灯光校验位于 `HanZombieShelter/lightstyle_audits/`，环境配置位于 `HanZombieShelterEnvironment/maps/`。普通 NPC 列表包括21种类型，对应模型从 HZS 上游资源包获取，入口见[安装与升级](安装与升级.md)。

[Boss五点片段](../examples/map-points/)用于查看或局部合并，完整配置已经提供，不必再次用片段覆盖。发行地图仅为上述两张 DN 图。

## 地图文件之间的关系

| 内容 | 位置／用途 |
| --- | --- |
| 地形、地图实体、内嵌资源 | `maps/<map>.bsp` |
| 原生 NPC 寻路 | 配套 `maps/<map>.nav` |
| 基地、采集点、安全区和 Boss 实例 | `configs/HanZombieShelter/maps/<map>.cfg` |
| 基地与 Boss 的类型参数 | `bases.cfg`、`bosses.cfg` |
| 普通怪与原生 Boss 数量 | `configs/HanZombieScenario/<map>/HanZombieScenarioStage.cfg` |
| NPC 名称、模型、基础属性与声音 | `HanZombieScenarioZombieData.cfg` |
| 昼夜视觉与独立灯光 | 地图环境配置、`lightstyle_audits/<map>.cfg` |

灯光校验与实际 BSP 内容绑定。改了 BSP，即使地图名相同，也不能直接沿用另一版本的校验。NAV 同样应对应实际地图，不能只复制一个同名文件。

## 新地图准备顺序

1. **准备可用地图。** 确认 BSP、NAV、客户端资源和真人出生区域，先保证玩家及普通 NPC 能正常活动。
2. **建立同名配置。** 准备 Shelter 地图文件和 HZS Stage，配置基地类型、基地位置、安全区、建造范围及采集点。
3. **选择 Boss 五点。** 在本图实地记录，检查各类 Boss 的体积、落地支撑和出口路线。
4. **配对 Boss 定义与数量。** 地图实例引用有效 Boss 类型，原生 Stage 中同 key 数量必须一致。
5. **完成环境配置。** 根据地图实际支持设置昼夜天空／灯组，生成并检查本图的灯光校验。
6. **实地检查。** 用真实地图验证落点、采集、建造、供电和 Boss 追击，保留失败点并修订候选。完成后撤掉采点助手和临时测试条件。

地图文件中的旧注释可能描述最初生成配置时的状态；实际安装使用当前同名配置、配套资源和有效键值，不以旧注释重新生成坐标。

## Boss 五点

`ShelterMap` 下需要 `BossSpawnPoints/boss1` 至 `boss5`。五个槽位必须齐全，即使这张地图只启用一只 Boss；五点只是位置池，不会自动生成五只 NPC。

- `origin` 为三个有限数字，各轴在 ±15000 内。
- `angles` 可省略，默认为 `0 0 0`；填写时各轴在 ±360 内。
- 有效 Boss 按定义顺序循环使用五点；超过五只可以共享位置，但必须自行检查空间。
- 不把一张地图的坐标复制到另一张 BSP；平台点应保留实际高度，不能擅自压到附近地面。

使用游戏坐标查看功能或自己的管理员采点工具记录位置。`origin` 应取玩家落地后的脚底坐标，朝向取水平 yaw；记录前关闭 noclip 并确认位置有稳定支撑。五个点记录齐全后，仍需分别检查模型体积、支撑和实际追击路线。

## Boss 类型、实例和 Stage

`bosses.cfg` 定义类型；地图 `Bosses` 中通过 `boss_profile` 引用类型，类型再通过 `han_config_key` 对应 HZS 定义。

| 默认地图 | `customzombies` |
| --- | --- |
| 沙漠 DN | `boss_pangzi:1,boss_angela:1,boss_yixing:1` |
| 死城 DN | `boss_pangzi:1` |

增加、删除或禁用实例时，同步调整 Stage。不要把同一个 Boss key 同时放入普通复生池，也不要把同 key 拆成重复 CSV 项。

当前配套 Stage 使用单个阶段、`count=99999`、`healthboost=0`、`maxszombiecount=0` 和有效普通怪列表。这些字段让昼夜求生负责其生存目标，不能按普通关卡模板随意改动。

Boss 胜利条件为所有有效启用实例死亡。`lifecycle.cfg` 的生存天数救援是另一条独立胜利条件。

## 实地检查要点

每种实际启用的 Boss 都应确认：完整体积不与地图实体相交、有稳定支撑，能够正常唤醒，并能由原生 AI 从目标点追到约定基地。不同 Boss 体积和路线表现可能不同，某个点到一个基地成功不代表所有基地都可达。

保留地图版本、Boss类型、起点、目标基地和失败原因。不要用搬运 Boss 到终点代替路线检查，也不要用失效的旧图配置作为当前默认。
