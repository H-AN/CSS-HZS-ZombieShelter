# 安装与升级

本仓库提供 HanZombieShelter 主插件、默认配置、配套地图与建筑资源，以及独立的外部兼容配置／资源。默认配置可直接使用，服主可按需要调整。

## 准备前置

| 内容 | 用途 |
| --- | --- |
| CS:S 服务端、Metamod:Source、SourceMod | 插件运行环境；当前配套使用 SourceMod 1.12 |
| 支持 `HanZombieScenarioAPI` 的 [HZS 主体](https://github.com/H-AN/H-AN-CSS-ZombieScenario)及其依赖 | 提供普通 NPC、Boss 及原生玩法接口 |
| HWS 与相应刀具插件 | 使用默认斧头、十刀合成配方时需要；不使用可停用相应配方 |
| 对应 HZS 丧尸技能插件 | 需要外部丧尸技能效果时安装；Shelter 自身不实现这些额外技能 |

仓库不附带 HZS、HWS、刀具或丧尸技能插件本体。先确认 HZS 能正常运行，再安装本项目。不要把 API 头文件或兼容配置当成插件已经安装。

HZS 的[示例模型材质.7z](https://github.com/H-AN/H-AN-CSS-ZombieScenario/blob/main/%E7%A4%BA%E4%BE%8B%E6%A8%A1%E5%9E%8B%E6%9D%90%E8%B4%A8/%E7%A4%BA%E4%BE%8B%E6%A8%A1%E5%9E%8B%E6%9D%90%E8%B4%A8.7z)提供与默认 NPC 配置对应的 23 种模型及配套材质、声音。可从该入口取得上游资源；同目录的 CF 僵尸包是另一套模型，不应直接替换当前默认配置的资源。

## 选择文件

完整使用当前默认地图和丧尸阵容，至少需要 **主插件文件＋主资源＋server-compat 中相应的丧尸资源**。武器功能再按需安装对应外部插件及兼容配置。

| 内容 | 仓库位置 | 说明 |
| --- | --- | --- |
| 主插件安装文件 | [`plugin/`](../plugin/README.md) | 主／环境 SMX、Shelter 配置、HZS 配套配置、正式翻译 |
| 主资源和地图 | [`resources/`](../resources/README.md) | `maps`、`models`、`materials`、`sound`、`scripts` |
| 默认丧尸与武器兼容内容 | [`optional/server-compat/`](../optional/server-compat/README.md) | 当前丧尸／Boss、斧头和十刀的额外资源，以及 HWS／刀具配置；不含外部插件本体 |
| NPC 追击距离补丁 | [`optional/npc-follow-range/`](../optional/npc-follow-range/README.md) | 可选 Windows x64 引擎补丁，有单独平台和互斥要求 |
| HZS 翻译补充 | [`optional/hzs-translations/`](../optional/hzs-translations/README.md) | 主体缺少翻译文件时使用，已有完整译文不覆盖 |

发行文件使用 `CSS-HZS-ZombieShelter-v0.8.3-` 前缀，按下面的后缀选择；使用默认组合需要前三个包。

| ZIP 后缀 | 用途 |
| --- | --- |
| `runtime.zip` | 主插件、环境组件、默认配置与翻译 |
| `resources.zip` | 主玩法资源、配套 BSP／NAV 和必要武器脚本 |
| `server-compat.zip` | 当前默认丧尸／Boss与武器的额外资源、HWS／刀具兼容配置 |
| `source.zip` | 主插件和环境组件的源码、API 与构建入口 |
| `optional-npc-follow-range.zip` | 独立追击距离补丁 |
| `optional-hzs-translations.zip` | HZS 主体翻译补充 |

解压后先读包内安装说明。旧的仅含少量资源的补充包不能替代当前主资源和兼容资源。兼容包保留了外部原配置已有的材质／音效缺项清单，不能据“模型文件已齐”认定所有外观和音效都无缺项。

## 首次安装步骤

以下目标目录均相对于服务端 `cstrike/`。

1. 安装并确认前置插件可正常工作，备份现有配置。
2. 将 `plugin/addons/` 合并到 `cstrike/addons/`。其中 `scripting/` 供编译使用，服务器只运行时可以不安装。
3. 将 `resources/` 下的 `maps`、`models`、`materials`、`sound`、`scripts` 分别合并到 `cstrike/` 下同名目录。不要多嵌套一层 `resources/`，也不需要覆盖游戏的 `scripts/game_sounds_weapons.txt`。
4. 使用当前默认 NPC 配置时，把 `optional/server-compat/resources/` 中对应目录也合并到 `cstrike/`。使用斧头／十刀时安装外部 HWS／刀具插件，并合并 `optional/server-compat/addons/` 中对应配置。
5. 同步 FastDL 或服务器现有下载渠道，让客户端得到相同的地图、模型、材质和声音。模型必须成组提供侧件，不能只复制 `.mdl`。
6. 启用配套地图，在正常维护／开服时加载插件和配置。检查 SourceMod 插件列表、错误日志和 `sm_zsh_status`。
7. 用真人客户端检查基地、资源、建造、供电、合成和昼夜效果，再开放给玩家。

已有 HZS／HWS 服务器应比较再合并：本仓库的 `configs/HanZombieScenario/` 和兼容 HWS 配置会影响对应外部插件的 NPC、武器及购买设置。不要连同服务器管理员、密码或其他无关配置一起替换。

## 默认地图配套

| 地图 | 当前默认组合 |
| --- | --- |
| `zsh_desert_han_dn` | 2 基地、3 Boss；普通 Stage 列表包含 21 种类型 |
| `zsh_deadcity_han_dn` | 6 基地、1 胖子；普通 Stage 列表包含 21 种类型 |

两张图的 BSP／NAV 位于主资源目录，完整 Shelter 地图配置、对应 HZS Stage、灯光校验和环境配置均随主插件文件提供。地图名、配置文件名和实际 BSP 版本必须对应，详见[地图适配](地图适配.md)。

`HanZombieShelterEnvironment.smx` 是昼夜视觉组件；使用天空及灯组变化时一起安装 `configs/HanZombieShelterEnvironment/`。它不替代地图所需的灯组和天空支持。

## 升级已有服务器

1. 备份正在使用的 SMX、翻译、地图、资源版本及实际配置。
2. 比较新默认与自己的设置，只应用需要的改动。当前默认包含采集基础收益 10、基地模型和 Boss 配套，不会自动保留其他服的旧平衡数值。
3. 将关联内容一起更新：模型及其侧件／材质、地图及 NAV／灯光校验、Boss 定义及原生 Stage、武器配方及外部命令。
4. 在安排好的维护时机让新地图／战役正常加载配置，保留玩家的自然进度和已有数据。
5. 检查日志，再检查实际玩家操作。

修改磁盘文件不会自动刷新进行中的战役。`sm_zsh_reload` 仅允许尚未建立战役时重试，不能用作任意时刻强制重读全部设置。玩家技能配置需要新地图会话。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 主玩法未启用 | 当前地图同名配置、完整 Boss 五点、对应 HZS Stage、HZS API 和错误日志 |
| 建筑模型报错 | 主资源是否成组安装；客户端是否收到同一套文件 |
| 普通怪或 Boss 模型缺失 | server-compat 的 NPC 资源、HZS ZombieData 中的模型路径、客户端下载 |
| 武器配方不可用 | HWS／刀具插件和命令、台型、等级、供电及个人材料 |
| 灯不亮 | 对应 BSP 的 `lightstyle_audits`、供电、昼夜和手动开关 |
| 没有昼夜视觉变化 | 环境插件、对应地图环境配置与地图灯组支持 |

主资源和兼容资源的已有缺项分别见各目录说明；缺失的声音或材质不能通过改名空文件来补齐。
