## 首次失败与修复记录

`integration_first`、`integration_second`、`power_third`、`power_verified`保留失败证据。初版测试错误地用假客户端管理员权限升级；SourceMod拒绝机器人管理员，随后错误恢复身份产生一段测试运行异常。修正后使用普通玩家付费升级路径。原生RemoveEntity完成存在延迟，删除断言改为逻辑引用立即失效、原生清理稍后复核。直接在Boss标记处创建的测试模型可能穿入地面；改为隔离空中战斗夹具，并在另一条生产地面建造路径经过原生物理初始化后验证升级和退天。没有通过放宽权限、移除碰撞或强行重建来让这些测试通过。

## 本轮范围与后续审阅

本轮没有新增HZS主体生成API、动态天空控制插件或重编地图。天空文档要求的三个接口名和环境语义已经正式落地，可供后续独立模块使用。

未进行本轮真人屏幕截图复核，不能沿用0.3的50张图作为新菜单或实际灯光画面的视觉验收。多人长时间负载、灯具客户端表现、榴弹对移动目标的命中率和经济平衡仍需实玩评估。当前模型是可用的原版引擎零件/泛光灯和旧炮塔外观，之后可替换专用美术。

## 安装与重现

0.4为正式SMX和完整配置集合；升级旧服前备份SMX、phrases及配置，新增4份配置，并合并炮塔/火焰/增强器的耗电字段，保留服主其他调参。涉及配置结构，应重新加载地图。安装包不包含HZS主体SMX、完整NPC资源或RCON密码。

正式部署：确认27129服0真人在线后，备份至服务端 `zsh_test_backup/v04_20261015_020814`，更新正式SMX、phrases、外部源码/API和7份涉及供电的配置，其余现场配置保留。仓库与部署文件哈希一致，生产运行只有昼夜0.4.0和原HZS2.3.2两插件，`zsh_test`为Unknown command。冷启动恢复后的PID为10600，后续PID以现场为准。

部署时执行的是 `changelevel zsh_desertplant_cso_v1_d`；进程在换图中退出，Windows Application Error记录异常模块 `steamclient64.dll`、代码 `c0000409`，没有SourceMod错误日志。已冷启动恢复0.4测试服并重新确认加载正常。用户随后确认其他插件换图也复现崩溃，当前按疑似本地服务器环境问题记录，用户明确要求暂不修复，不纳入本轮插件修复范围。运行中的换图统一使用changelevel；启动参数+map只用于初始地图。

本机可用以下命令重现独立回归，先确认该隔离目录的服务器已退出：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -IntegrationProbe

D:\python\python.exe .\tools\test_local_server.py --server-root .\tests\runtime\v04_server --port 27139 --integration --power --report-dir .\tests\reports\v04\new_run
```

正式运行检查先执行 `prepare_isolated_server.py --production`，runner省略 `--integration`。不要把测试SMX或API消费者装进正式交付的plugins目录。
