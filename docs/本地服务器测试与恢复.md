## 启动和连接

正式二进制安装完后，只加载`UnmodifiedHZS.smx`和`HanZombieShelter.smx`。其中前者从主体仓库原样编译；后者是本仓库的生产构建。测试探针SMX已经撤下。

从仓库运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Start-LocalShelter.ps1
```

也可运行已复制到服务器根目录的`启动昼夜求生测试.ps1`。默认隐藏启动，只绑定本机`127.0.0.1:27129`；客户端控制台输入：

```text
connect 127.0.0.1:27129
```

启动脚本生成本机RCON密码并保存在服务器根目录`.zsh-local-rcon.txt`，或使用`-RconPassword`传入自己的密码。这个文件不进入仓库/安装包。读出密码后在客户端设置`rcon_password`，然后执行`rcon sm_zsh_status`、`rcon sm_zsh_phase night`等测试命令。

先用RCON执行`sm_zsh_fail`结束战斗，等待回合结束，再执行`sm plugins unload UnmodifiedHZS`和`quit`。先卸载主体让原有结束逻辑在GameRules仍有效时运行，可避开旧主体的引擎关服顺序异常。直接关窗口也会关闭进程，但旧主体可能记录同类关服异常。

测试是服务端自动验证，不宣称已执行客户端Hijack输入或多人实战。地图此前的客户端资源验证不等于新玩法UI已经人工试玩。经济与多人压力仍需要后续实际游玩。

当前准备好的测试服可以复跑生产检查：`python .\tools\test_local_server.py`。完整70项检查需要先停止服务器，运行`build.ps1 -IntegrationProbe`，将`tests/compiled/ShelterIntegrationProbe.smx`暂时复制为服务器的`plugins/HanZombieShelter.smx`，再运行`python .\tools\test_local_server.py --integration`。测试后用仓库`addons/sourcemod/plugins/HanZombieShelter.smx`替换回正式构建。脚本自动启动/关闭自己的测试进程，报告默认写`tests/reports`；不会替你重装配置或更改主体源码。

```powershell

```

脚本先验证全部备份哈希和绝对路径，再逐文件恢复旧文件、移除本次新增文件和停用后缀。没有递归删除目录，备份和测试日志保留。无需执行恢复就可以继续测试当前昼夜服。
