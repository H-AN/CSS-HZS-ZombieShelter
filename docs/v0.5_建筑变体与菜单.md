# v0.5 建筑变体、等级与菜单

实现日期：2026-10-15。本文件描述代码已经接入的字段；编译和隔离逻辑检查不等于真人画面、真人多人或模型碰撞体验验收。

## 配置目录

继续分别编辑 `turrets.cfg`、`flame_turrets.cfg`、`grenade_turrets.cfg`、`mines.cfg`、`fences.cfg`、`generators.cfg`、`amplifiers.cfg`、`lights.cfg`、`expanders.cfg`。行为来自文件类别；同类所有 Types/BuildRecipes 复用已有逻辑。使用门模型的工事仍是静态障碍。

每个文件保留 `Types/<type_id>` 与 `BuildRecipes/<recipe_id>`，配方通过 `output_type` 引用类型。目录上限为全服 **256 个有效配方**，与存活建筑数分开；超量项写日志并跳过。稳定 ID 不得包含 `/` 或 `:`。新增或复制类型无需新增 Kind、Timer 或翻译词条。新建筑文件 schema 为 2；加载器仍允许旧建筑 schema 1 沿用缺省字段。

显示名称优先配方 `display_name`、类型 `display_name`、类型 ID；只有实际存在翻译词条才翻译，否则原样显示。`description` 也可使用原文或已有翻译词条。翻译生成器默认接受配置 `display_name` 的原文，不再要求每增加一个中文变体就改 Python；结局提示等已有词条检查继续保留。

## 类型元数据

字段均相对 `Types/<type_id>`：

| 字段 | 实际语义 |
| --- | --- |
| `model` | 服务器需能预缓存的主模型；缺失禁用对应配方 |
| `render_rgb` / `render_alpha` | 默认 `255 255 255` / `255`，每通道夹到 0..255；材质可能限制染色效果 |
| `skin` | 默认 0，先限制 0..255；可通过挂载 GAME 文件系统读取 IDST v44..49 模型时，再按实际 skin families 限制；夹值记日志 |
| `Placement/mode` | `upright` 直立、`surface` 贴合法线、`wall` 墙面安装 |
| `Placement/origin_offset` | 模型局部 X/Y/Z 的最终轴心偏移，替代旧统一包围盒抬高 |
| `Placement/angle_offset` | Source pitch/yaw/roll 局部修正；创建/恢复保持同一变换 |
| `Placement/allow_overlap` | 默认 1，允许基地内、顶部、建筑叠放；显式 0 才启用严格空间检查 |
| `Placement/max_distance` | 默认 512，合法范围 16..4096；取当前眼睛射线命中点 |
| `Attachments/muzzle_offset` | 模型局部炮口偏移；机枪/火焰缺省 `0 0 48`，榴弹 `0 0 64` |
| `Attachments/light_offset` | 模型局部灯源偏移，缺省 `0 0 64` |
| `Sounds/build/attack/upgrade/destroy` | 相对 sound 的样本；也接受开头 `sound/` 并规范化；缺失/无效样本回退类别默认 |
| `Downloads/<任意唯一键>` | 值为单个完整下载路径，如 `models/example.vvd`、`materials/example.vmt`、`sound/example.wav`；逐文件登记，不递归扫描 |

局部坐标为 **X 向前、Y 向左、Z 向上**。炮口按有效实体实际角度变换；实体不存在时使用保存角度。不能把局部 X/Y 偏移直接加到世界 X/Y。建造保存最终 origin/angles，退天恢复不重复追加偏移。

音效仅实际成功建造/升级/毁坏/开火时播放。空 build 回退 `sounds.cfg/build_place`，upgrade 回退 `build_complete`，destroy 回退 `destroyed`；原攻击无统一默认声音，因此 attack 留空保持原行为。自定义声音验证、预缓存后登记下载。内置/地图已有资源仍需客户端拥有相应游戏与地图。

## 等级和成本

详情与实际建造、升级共用 Levels 解析器。显式等级字段优先；Growth 中未覆盖属性始终从 anchor 按字段推导，不从最近一个显式等级继续累加。正值 fire_interval 小于 0.1 时规范为 0.1 并在加载期告警；0、负值、无法解析的数值使相应类型失效。

显式 `Levels/L/upgrade_cost` 整体替代该等级公式成本，未列材料为 0；没有显式节点时才使用 anchor 成本加每级增量。所有材料通过登记 ID 检查，未知 ID 不能变为免费建造或升级。无效普通建筑类型/配方单独跳过，仍有效的其他类别继续加载；地图基地 profile 无法解析仍会拒绝该地图模式。

新增等级字段已进入解析器、Growth 白名单与边界检查：

| 字段 | 类型 / 合法范围 |
| --- | --- |
| `build_limit` | 基地本级基础配额，整数 0..1024；另受基地硬上限和全服预算约束 |
| `build_limit_bonus` | 扩大器本级总配额贡献，整数 0..1024 |
| `build_range_bonus` | 扩大器本级对四边的扩张，0..8192 |
| `build_half_extents_x/y` | 基地本级矩形半长，正数且不超过 8192；支持 `_per_level/_min/_max` |
| `build_half_extents` | `x y 0` 向量别名；缺省 `500 400 0`，标量 x/y 可覆盖 |

Growth 通过 anchor 向量提供缺省半长，再叠加标量 x/y 的逐级规则；当前等级显式向量整体覆盖其向量缺省。高度由地图 BuildArea 单独配置，向量第 3 格不扩张建造高度。扩大器升级替换旧总贡献，不累计历史等级。

一场战役使用同一 configRevision。实例保存外观、声音、偏移和配置修订，未来升级读取该修订的只读 profile；修订不一致时拒绝报价。已有快照/战役准备期间拒绝结构重载，磁盘改动不会自动更新当前实例。

## 菜单与事务

流程为 **类别 → 变体 → 详情 → 确认**，至少有一个有效配方才显示类别。详情列当前与下一等级的真实属性、材料余额、最高等级、Growth 锚点及当前瞄准归属基地/配额。非攻击设施不显示虚构伤害和射速，地雷显示一次性行为。属性/材料通过禁用行分页展示，不把最多 64 材料塞进一个会截断的标题。

打开菜单不扣费。确认使用当下视线重新计算落点，并保持确认菜单显示的所属基地；瞄准跨到另一基地会要求重新查看确认。确认重新检查余额、范围、配额、等级前置和引擎预算，创建失败按事务退款。

建造选择绑定 epoch、客户端 serial、配置 revision、稳定文件/配方/类型 ID 与每客户端一次性 nonce。每次有效导航、失败或提交先消费 nonce。旧菜单不会依赖数组下标重新解释配方。设施管理额外校验 UID、generation、等级和权限。

背包命令、升级材料、退款及基地仓库均遍历已登记材料。仓库存取 token 将 operation、material ID、quantity 分别编码，数量支持 1、10、全部；材料超过十种时不会与原来的操作码范围碰撞。

基地/设施管理与升级标题显示所属基地、当前建筑数/有效上限和超额量；扩大器另显示当前有效/无效状态，以及当下实际贡献的每侧范围与名额。无效时贡献为 0，配置的等级属性仍可在下方查看。`real_client_04_management` 已实际用 E 打开机枪塔管理页并查看截图，确认基地 A、1/24、超额 0 和属性页在 1280×720 显示完整。
