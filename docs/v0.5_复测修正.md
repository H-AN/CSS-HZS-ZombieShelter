## 引擎跟随和无目标处理

曾按授权在隔离服试验 guarded BOT 初始化补丁与定向跟随补丁：前者写入及校验成功，后者初始 ready／NOP／Idle 成功，但随后发生运行期 AV。用户要求失败后停止纠结，两个辅助补丁最终停用，不再追查；保留原作者署名、源码和全部失败证据，详见 [定向引擎补丁核对](v0.5_定向引擎补丁核对.md)。最终使用不依赖引擎补丁的 B 计划，不能称已解除引擎 2000 直线／4000 路径限制或修好远距离跟随。

B 计划中的“无目标”按 HZS 人质 NPC 处理。活跃普通 NPC 没有有效目标时，每 0.5 秒最多补选一次最近存活真人，等距随机；选目标本身没有射线或距离上限。Boss 必须先按既有受伤条件唤醒，只有唤醒后才参与 nearest 补目标，不能为了补目标唤醒 Boss。保留现有有效目标，仅加 0.75 秒短锁，不永久劫持索敌。隐藏池、未醒 Boss、暂停／停车与正在攻击建筑的 NPC 不接管。玩家断线同步解除相关短锁并清理目标 serial。此兜底与引擎的实际跟随距离、nav 可达性分开，不能以赋目标成功代替远途移动验收。

本轮保持零 BOT，不绕过主体 `Cmd_BlockAddBot`，不创建 FakeClient 或复活 NPC。最终默认发行加载目录不含两个辅助补丁 SMX，27129 录制服保持原样。

## 防御工事

原“围栏”分类和默认名称统一改为“防御工事”，保留旧枚举值、配置文件/类型/配方 ID；自定义变体名称仍使用各自配置。

只有 `Kind_Fence` 类可旋转。瞄准近处设施按 E，管理菜单选择垂直或水平，进入后有 +5°/-5° 和返回。每次操作保留同轴菜单，玩家自行关闭；保存实际 pitch/yaw 并更新实体与恢复包围盒，不重新扣料。连续步进检查原 UID、generation、serial、epoch、revision、权限和实际旋转后 OBB 距离，不要求每次重新命中旋转后的薄面。升级、拆除、初次进入和接管仍保留原瞄准检查。

第 08 次真人回归确认垂直连续操作已生效，但旋转后点击返回会因薄面射线移开而提示菜单过期。修正为旋转专用返回操作 13，以及返回管理页后的垂直/水平操作 14/15；这些操作沿用已选工事的身份、权限与 OBB 距离校验。管理页编号仍为 3 垂直、4 水平，原操作 0 与初次入口 6/7 不变；其余管理动作仍独立要求真实瞄准。测试步骤保留原点击顺序，新增返回管理页截图和转开视线后的导航/权限断言，实际复测结果另行记录。

可选等级字段 `damage` 表示该类工事被 NPC 实际攻击时的反伤，未填或 0 不反伤。沿用 Levels/Growth 的 `damage` 解析；默认铁丝网补 10，已有显式值包括 0 均保留，HP 和费用不改。反伤沿现有设施成长通道。普通建筑、玩家射击、维修、回收不触发；NPC 的同一个 nextAttack 周期只打一次。致死工事先捕获当次身份，工事移除后仍反一次，不读可能复用的旧建筑槽。

真实伤害/奖励归属优先当前在线主人；玩家离线后工事可通过 E 接管，接管者成为当前主人。无主时随机选择一个在线真人作为当次真实归属；无真人则不造成反伤。在线已死亡主人仍使用本人，已核对 HZS 2.3.2 安全伤害 API 接受在线 player 实体，不需要另造伤害代理。

## 管理员回城与商店接入

管理员新增回城列表，动态显示存活基地 A/B/C，选中后只到该基地的有效安全落点。检查绿区、玩家 hull、落地支撑及占位，速度归零；基地已毁或没有落点则失败，不换去另一基地。

公共 API 追加两个 optional native（旧接口和枚举保持兼容）：

```sourcepawn
native bool HZSH_TeleportPlayerToBase(int client, int coreUID);
native bool HZSH_ShowBaseTeleportMenu(int client, Function onSelected, any context=0);
// void onSelected(int client, int coreUID, any context)
```

选择菜单只返回 UID，不传送、不扣费；取消/超时/失效回调 UID=0。商店回调重新校验订单与余额，调用指定 UID 传送，返回 true 后再确认扣分；异步商店自行管理积分预留/提交/释放。调用插件、客户端代次与配置修订绑定，回调前先消费事务，插件卸载后不调用失效函数。没有实现钱、积分、普通玩家回城命令或存档。完整契约和示例见 [公开 API](昼夜求生公开API.md)。
