# CSS-HZS-ZombieShelter

**Counter-Strike: Source 合作昼夜求生插件 · v0.8.3**

白天搜集材料、修建基地和防御设施，夜间守住供电与安全区；升级角色技能、制作工具，与队友共同击败地图 Boss，或坚持到救援到来。

默认配置可直接使用，服主可以按人数、地图和难度调整。

[发行下载](https://github.com/H-AN/CSS-HZS-ZombieShelter/releases) · [安装与升级](docs/安装与升级.md) · [玩家操作](docs/玩家操作.md) · [配置说明](docs/配置说明.md) · [地图适配](docs/地图适配.md)

## 可以玩什么

| 玩法 | 内容 |
| --- | --- |
| 昼夜生存 | 白天准备，夜晚防守；安全区外有夜间暴露伤害，篝火可提供临时庇护 |
| 采集与材料 | 木、铁、铜、银、金，以及击杀／合成获得的瘟疫核心和生存币；资源耗尽后再生 |
| 基地建设 | 建造预览、实际施工、维修、升级、取消未完工工程、拆除和共享仓库 |
| 电网与设施 | 发电机、照明、范围扩大器、自动维修站、治疗站、护甲站和恢复信标 |
| 防御建筑 | 机枪／多管／火焰炮塔、榴弹与迫击炮、电击线圈、离子炮、地雷、路障、墙体和瞭望塔 |
| 角色成长 | 采集、施工、维修、移速、跳跃、夜间暴露免疫、团队支援、自动恢复及血甲上限技能 |
| 合成台 | 制作斧头和十刀配方，合成材料，升级台等级解锁更高阶工具 |
| 生存目标 | 击败本图所有启用 Boss，或达到配置的生存天数完成救援 |

普通丧尸和 Boss 由 [HZS 大灾变主体](https://github.com/H-AN/H-AN-CSS-ZombieScenario)提供，模型和材质可从其[示例资源包](https://github.com/H-AN/H-AN-CSS-ZombieScenario/blob/main/%E7%A4%BA%E4%BE%8B%E6%A8%A1%E5%9E%8B%E6%9D%90%E8%B4%A8/%E7%A4%BA%E4%BE%8B%E6%A8%A1%E5%9E%8B%E6%9D%90%E8%B4%A8.7z)获取。额外丧尸技能、HWS 武器和刀具系统需安装相应插件；本插件负责昼夜求生与建筑玩法。

## 第一次进入怎么玩

1. **先找基地。** 基地安全区内按 **E**，查看基地状态、升级、仓库、建造和玩家技能。
2. **拿刀或斧头采集。** 使用刀槽中的工具左击资源点，材料进入个人背包；枪械不用于采集、施工或维修。
3. **建造并完工。** 打开建造菜单，选设施、查看费用、确认预览位置；蓝图落下后继续用工具左击施工。未完工设施不能正常使用。
4. **先准备供电。** 将发电机和耗电设施布置在所属基地范围内；供电不足时检查发电机耐久、产能及设备需求。
5. **迎接黑夜。** 提前回安全区，维修防线并补充篝火燃料。升级技能和合成工具，提高后续白天的准备效率。

### 常用操作

| 操作 | 用途 |
| --- | --- |
| 基地安全区内按 **E** | 打开基地菜单 |
| 建造范围内按 **E** | 打开建造菜单；近距离瞄准设施时优先操作该设施 |
| 基地与建造范围外按 **E** | 打开建造／玩家技能快捷菜单 |
| 近距离瞄准完工设施按 **E** | 打开设施管理；合成台进入武器／材料合成菜单 |
| 刀槽工具 **左键** | 对资源采集，对蓝图施工，对受损建筑维修 |
| 刀槽工具 **右键**瞄准未完工工程 | 有权限时取消工程，返还实际已投入材料 |
| 刀槽工具 **右键**瞄准已完工篝火 | 消耗木材补充燃料；左键仍用于维修耐久 |
| 瞭望塔附近或平台上按 **E** | 打开塔菜单，使用上塔／下塔功能 |
| 聊天 `!build`、`!materials`、`!zsh_skills` | 分别打开建造、材料、玩家技能菜单 |

详细规则和操作问题见[玩家操作](docs/玩家操作.md)。

## 当前默认玩法

| 项目 | 默认设置 |
| --- | --- |
| 昼夜 | 白天 180 秒、夜晚 180 秒，入夜前 30 秒预警 |
| 夜间暴露 | 离开有效安全区／篝火庇护时，每秒造成 1 点暴露伤害 |
| 采集 | 五种基础材料每次有效命中的基础收益为 10，再受工具和技能影响 |
| 技能 | 每天 2 点；多数技能最高 20 级，重力技能最高 9 级 |
| 合成台 | 最高 10 级，每基地最多 1 台；耗电从 50 逐级增加到 320 |
| 胜利 | 击败本图全部启用 Boss，或完成默认 30 天生存目标 |

以上均可通过配置调整。篝火和夜间免疫技能只针对暴露伤害，不等于免疫丧尸攻击。

## 安装

准备好可正常运行的 **CS:S 服务端、Metamod:Source、SourceMod 和 HZS 主体**。现有配套以 SourceMod 1.12 为基准。

使用默认组合时，下载同一版本的 `runtime.zip`、`resources.zip`、`server-compat.zip` 三个包。可选追击补丁另行安装；完整包名与用途见[安装说明](docs/安装与升级.md)。

| 仓库内容 | 放到服务器的位置 |
| --- | --- |
| `plugin/addons/` | 合并到 `cstrike/addons/` |
| `resources/` 内的 `maps`、`models`、`materials`、`sound`、`scripts` | 各自合并到 `cstrike/` 下同名目录 |
| `optional/server-compat/resources/` 内的资源目录 | 使用默认丧尸／Boss与刀具配置时，合并到 `cstrike/` 下同名目录 |
| `optional/server-compat/addons/` | 使用对应 HWS／刀具功能时，合并到 `cstrike/addons/` |

**默认丧尸资源分布在主资源包和 server-compat 中，需要一起安装。** 主资源目录中的 `putonghe` 只是其中一部分；额外普通丧尸、安哥拉和异形等模型在兼容资源目录中。 该目录提供配套配置和资源，不包含 HZS、HWS、刀具或丧尸技能插件本体。斧头及十刀配方需要相应武器命令；不使用这些功能时可在配方配置中停用。

服务器文件安装后，还要配置客户端资源下载。已有服务器升级前备份原配置，只应用自己需要的改动。完整步骤、依赖和下载包选择见[安装与升级](docs/安装与升级.md)。

## 服主可以配置什么

主配置目录为 `addons/sourcemod/configs/HanZombieShelter/`。

| 想调整 | 从这里开始 |
| --- | --- |
| 昼夜时长、暴露伤害、交互距离 | `mode.cfg` |
| 生存天数、失败后的恢复规则 | `lifecycle.cfg` |
| 丧尸数量、每天的血量与伤害成长 | `days.cfg`、`zombies.cfg` |
| 材料收益、资源再生、击杀掉落 | `resources.cfg`、`materials.cfg`、`zombie_drops.cfg` |
| 基地和建筑费用、耐久、等级、数量限制 | `bases.cfg`、`management.cfg` 及各设施配置 |
| 发电量、设备耗电、缺电模式与灯光 | `power.cfg`、`generators.cfg`、`lights.cfg` |
| 炮塔伤害、射程、射速、特效和升级 | 对应炮塔配置 |
| 玩家技能点、等级上限、效果与洗点费用 | `skills.cfg` |
| 合成台等级、武器／材料配方、工具工效 | `workbenches.cfg`、`weapon_crafting.cfg`、`material_crafting.cfg`、`weapons.cfg` |
| 地图基地、采集点、Boss 数量与位置 | `maps/<地图名>.cfg`、`bosses.cfg`，并同步 HZS Stage |

完整文件表和修改示例见[配置说明](docs/配置说明.md)。

## 常见问题

- **建筑是 ERROR 或贴图缺失：** 检查主资源、兼容资源和客户端是否都安装完整，不要只复制 `.mdl`；模型侧件和材质也需要一起提供。
- **建筑放下后不能使用：** 先完成施工，再检查所属基地、供电、等级和数量限制。
- **合成台配方灰色：** 检查台型、等级、电力、个人材料，以及外部武器命令是否存在。
- **换地图后玩法没有启动：** 核对地图同名配置、对应 Stage 和完整五点；新地图需单独适配。
- **改配置没有立即生效：** 在维护时机让新地图／战役正常加载配置；技能设置需要新地图会话。

部分外部配置引用的材质／音效原件仍有已知缺项，可能影响局部显示或声音，详见兼容包说明与缺项清单。反馈问题请附地图名、插件版本、复现步骤及相关错误日志。
