# 安装与升级

本仓库提供 HanZombieShelter 插件、默认配置、配套地图与建筑资源。服务端运行环境和 HZS 等外部插件需自行安装；服主可在默认配置基础上调整玩法。

## 准备前置

| 内容 | 用途 |
| --- | --- |
| CS:S 服务端、Metamod:Source、SourceMod **1.12 或更高版本** | 插件运行环境 |
| 支持 `HanZombieScenarioAPI` 的 [HZS 主体](https://github.com/H-AN/H-AN-CSS-ZombieScenario)及其依赖 | 必需，提供普通 NPC、Boss 及玩法接口 |
| [HWS](https://github.com/H-AN/H-AN-CSS-HanWeaponSystem)与 [DeltaForceKnife](https://github.com/H-AN/H-AN-CSS-Delta-Force-Knife) | 使用默认斧头、十刀合成配方时，按配方所调用的命令安装对应插件和资源；不用这些配方可停用 |
| [HZS 技能配套插件](https://github.com/Ducheese/hzs-supporting-plugin) | 使用对应外部丧尸技能效果时安装；Shelter 自身不提供这些额外技能 |

先按上游说明安装并确认 HZS 能正常运行，再安装本项目。仓库中的 API 头文件和 HZS 配套配置不能替代外部插件本体。

使用当前默认 NPC 阵容，还需取得 HZS 的[示例模型材质.7z](https://github.com/H-AN/H-AN-CSS-ZombieScenario/blob/main/%E7%A4%BA%E4%BE%8B%E6%A8%A1%E5%9E%8B%E6%9D%90%E8%B4%A8/%E7%A4%BA%E4%BE%8B%E6%A8%A1%E5%9E%8B%E6%9D%90%E8%B4%A8.7z)。该包提供默认配置对应的 23 种 NPC 模型及配套资源；同目录的 CF 僵尸包是另一套模型，不能直接替代。

## 选择文件

| 内容 | 仓库位置 | 说明 |
| --- | --- | --- |
| 插件安装文件 | [`plugin/`](../plugin/README.md) | 主插件、环境组件、默认配置、HZS 配套配置与翻译 |
| 地图与建筑资源 | [`resources/`](../resources/README.md) | 下载 `resources.zip.001` 和 `resources.zip.002` 两个分卷 |
| 纯源码 | [`src/`](../src/) | 自行修改或编译时使用，见[编译说明](开发与API.md) |
| NPC 追击距离补丁 | [`optional/npc-follow-range/`](../optional/npc-follow-range/README.md) | 可选 Windows x64 引擎补丁，按其说明确认平台和互斥要求 |
| HZS 翻译补充 | [`optional/hzs-translations/`](../optional/hzs-translations/README.md) | 主体缺少翻译文件时使用，已有完整译文不覆盖 |

使用默认地图和 NPC 阵容时，需要本项目插件、两个主资源分卷，以及上面的 HZS 插件和 NPC 资源。启用武器或外部技能时，再从对应项目取得其插件、配置和资源。

## 首次安装步骤

以下目标目录均相对于服务端 `cstrike/`。

1. 安装前置并确认可正常工作，备份现有配置。已有 HZS 服务器应先比较本仓库 `plugin/addons/sourcemod/configs/HanZombieScenario/` 与自己的配置，再合并需要的改动。
2. 将 `plugin/addons/` 合并到 `cstrike/addons/`。其中 `scripting/` 供编译使用，服务器只运行插件时可以不安装。
3. 将 `resources.zip.001`、`resources.zip.002` 下载到同一目录，保持原文件名。用 7-Zip 打开或解压 **`resources.zip.001`**，程序会自动读取第二个分卷。不要分别解压 `.002`、改名或手动拼接分卷。
4. 将解压得到的 `maps/`、`models/`、`materials/`、`sound/`、`scripts/` 合并到 `cstrike/` 下同名目录。例如地图应位于 `cstrike/maps/`，不要多嵌套一层 `resources/` 或解压目录。
5. 按 HZS 资源包说明安装默认 NPC 模型及配套材质、声音；使用 HWS、刀具或外部技能时，按对应项目说明安装其配套文件，并核对合成命令与模型路径。
6. 同步 FastDL 或服务器现有下载渠道，让客户端得到相同的地图、模型、材质和声音。模型必须连同侧件和材质一起提供，不能只复制 `.mdl`。
7. 在正常维护或开服时加载配套地图和插件，检查 SourceMod 插件列表、错误日志和 `sm_zsh_status`，并用真人客户端检查基地、采集、建造、供电、合成和昼夜效果。

本项目不需要覆盖游戏自带的 `scripts/game_sounds_weapons.txt`。安装和升级也无需替换服务器管理员、密码等无关配置。

## 默认地图配套

| 地图 | 当前默认组合 |
| --- | --- |
| `zsh_desert_han_dn` | 2 基地、3 Boss；普通 Stage 列表包含 21 种类型 |
| `zsh_deadcity_han_dn` | 6 基地、1 胖子；普通 Stage 列表包含 21 种类型 |

两张图的 BSP／NAV 在主资源压缩包中，完整 Shelter 地图配置、对应 HZS Stage、灯光校验和环境配置随 `plugin/` 提供。地图名、配置文件名和实际 BSP 版本必须对应，详见[地图适配](地图适配.md)。

`HanZombieShelterEnvironment.smx` 是昼夜视觉组件；使用天空及灯组变化时一起安装 `configs/HanZombieShelterEnvironment/`。它不替代地图所需的灯组和天空支持。

## 升级已有服务器

1. 备份正在使用的 SMX、翻译、地图、资源版本及实际配置。
2. 比较新默认与自己的设置，只应用需要的改动。默认配置中的采集收益、基地模型、Boss 和武器配方等数值可按自己的服务器需求保留或调整。
3. 将关联内容一起更新：模型及其侧件／材质、地图及 NAV／灯光校验、Boss 定义及 HZS Stage、武器配方及外部命令。
4. 在安排好的维护时机让新地图／战役正常加载配置。
5. 检查日志，再检查实际玩家操作。

修改磁盘文件不会自动刷新进行中的战役。`sm_zsh_reload` 仅允许尚未建立战役时重试，不能用作任意时刻强制重读全部设置。玩家技能配置需要新地图会话。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 资源压缩包无法解压 | 两个分卷是否都下载完整、位于同一目录且文件名未变；是否从 `.001` 开始解压 |
| 主玩法未启用 | 当前地图同名配置、完整 Boss 五点、对应 HZS Stage、HZS API 和错误日志 |
| 建筑模型报错 | 主资源是否完整解压并成组安装；客户端是否收到同一套文件 |
| 普通怪或 Boss 模型缺失 | HZS 示例模型材质包、HZS ZombieData 中的模型路径、客户端下载 |
| 武器配方不可用 | HWS／刀具插件和命令、台型、等级、供电及个人材料 |
| 灯不亮 | 对应 BSP 的 `lightstyle_audits`、供电、昼夜和手动开关 |
| 没有昼夜视觉变化 | 环境插件、对应地图环境配置与地图灯组支持 |

外部插件资源以对应项目的配套版本为准。遇到材质或声音缺失时，按日志中的路径检查服务端和客户端文件，不能用空文件补齐。
