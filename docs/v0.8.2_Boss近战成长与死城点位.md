## Boss普通近战、技能与建筑伤害

用户确认Boss对玩家的原生普通近战基础伤害为30，并随普通怪既有的天数伤害倍率增长。基础30来自外部HZS对应Boss的 `damage` 配置；Shelter只在确认原生普通近战事件后使用已有的 `PlayerDamageScale()`，不把30硬编码成所有来源的最终伤害。

Boss技能也可能使用相同实体和 `DMG_SLASH`，因此仅凭伤害类型不足以区分。本轮通过HZS原生 `Han_OnZombieAttack` 建立一次性近战凭据，绑定NPC完整ref、本轮epoch、受击真人serial和当前引擎tick；只有对应的即时直接伤害可消费该凭据。技能、间接弹射物、PVP／世界伤害与Exposure保留原规则，不因看见 `DMG_SLASH` 就跟随Boss近战放大。

Boss攻击建筑继续读取Shelter Boss类型中的 `building_damage=120`，不套玩家近战倍率。原有角色技能、Boss技能伤害、外部武器攻击／动画／音效均不借本次普通近战调整改值。攻击者、受击者、墙体与实体等离线适配器验证不能代替真实Boss战斗平衡或多人负载验证。

## 外部HZS只迁移三个damage叶

随包迁移工具为[tools/migrate_v082_boss_damage.py](../tools/migrate_v082_boss_damage.py)，仅使用Python标准库，不依赖另外的KV parser或外部源码仓库。它只允许修改：

```text
zombies/boss_pangzi/damage
zombies/boss_angela/damage
zombies/boss_yixing/damage
```

精确原值10改为30，已经为30则保持；缺目标、未知原值、重复／大小写别名键、非合法KV均拒绝。工具生成独立候选、原始字节备份和叶级／字节回执，保留其余所有源码字节、注释、换行和BOM；不整份重排外部配置，也不直接写固定live ROOT或覆盖源文件。

示例只生成离线候选，不部署：

```text
python tools/migrate_v082_boss_damage.py --source <现有HanZombieScenarioZombieData.cfg> --output <独立候选目录/HanZombieScenarioZombieData.cfg>
```

HZS存在每图 `configs/HanZombieScenario/<map>/HanZombieScenarioZombieData.cfg` 覆盖时，应单独审查其实际优先级。工具对官方全局路径会扫描覆盖文件，发现覆盖即停止；源是另存备份时应提供 `--override-dir` 指向实际HanZombieScenario配置目录。生成候选与实际安装、HZS在正常mapstart重读数据是不同事件，不能用磁盘值30代替本轮运行数据已加载的证据。

[19:53配置部署回执](../tests/reports/v082_boss_damage_20261025/native_damage_config_deployment.json)记录三个原生近战叶10→30、其余字节保持，输出SHA256 `d990005adad7f7243ecf18802b7fdfef2238a6605bf8d72ba7d6a2f54ab081f0`；该时点仍需下一次HZS正常 `OnMapStart`。20:18:37通过固定ROOT正式入口新进程加载死城后，HZS已在本次mapstart读取该文件，见[最终会话](../tests/reports/v082_deadcity_routes_20261025/final_session.json)。这证明加载时机，不把磁盘与进程身份核对写成新伤害真人受击实测。
