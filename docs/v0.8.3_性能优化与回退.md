本版优化昼夜求生的实体查询、电网、资源维护、增伤配置读取与建筑遍历。HZS 主体、HWS、公共 API 签名、配置数值、资源包、BSP、刀具收益／反馈和调度周期保持。没有承诺整服无卡顿、无泄漏或5Mbps足够多人使用。

遍历按原槽位顺序，UID排序仅用于原有供电优先规则。RuntimeNext遇到结构变化会重建并按“上次槽位之后”继续，避免回调期间删除／新建造成跳项。哈希均摊快速查询，不承诺恶意碰撞时严格O(1)；存储固定，不随累计UID或最大等级无限增长。

**本轮没有采用的条件项**

三个常驻共享定时器仍为World请求0.25秒、防御请求0.1秒、弹道请求0.05秒，各设施仍按自己的CD/deadline执行；没有逐建筑射击计时器。请求0.05不等于实际稳定20Hz。这里先减少回调内工作，不为减少两个共享调度项改变弹道和执行顺序。

PowerTick保留周期维护与结算，但只访问实际成员、复用排序并抑制重复效果输入。无变化时整次跳过、HUD全文缓存、移动NPC空间网格、冻结／燃烧集合、支撑邻接表及统一调度仍是测量后选择项。本轮未把它们写成已实现；BeaconTick/CampfireTick等涉及旧残留状态清理的容量循环保留。
